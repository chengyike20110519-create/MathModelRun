# 竞赛适配包

本目录可存放不同数学建模竞赛的定制模板与规则。

## 当前占位

- `cumcm/`：全国大学生数学建模竞赛（CUMCM）
- `mcm/`：Mathematical Contest in Modeling / Interdisciplinary Contest in Modeling
- `himcm/`：High School Mathematical Contest in Modeling

每个子目录可包含：

- `paper-template.typ` / `paper-template.tex`
- `rules.md`
- `scoring.md`
- `sample-data/`

欢迎提交 PR 补充完整模板。
